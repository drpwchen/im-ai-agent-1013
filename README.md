# ai-agent-demo

讓 AI 檢查一張值班表的小練習。**裡面全部是虛構資料**：人名是「甲醫師」到「己醫師」，
規則是為了示範編的，沒有任何真實的病人、同事或醫院資料。

## 練習一：整理好的資料

根目錄的四個檔就是練習一：規則已經寫成條列，資料也整理成表。

### 檔案

| 檔案 | 是什麼 |
|---|---|
| `值班規則.md` | 六條排班規則 |
| `人員.csv` | 六位醫師的職級，以及能不能接受隔日值（QOD） |
| `請假.csv` | 誰在哪幾天請假 |
| `值班表-2026-11.csv` | 2026 年 11 月的值班表，**故意排錯了幾個地方** |

### 怎麼用（claude.ai 網頁版）

1. 打開 claude.ai，開一個新對話。
2. 從輸入框的「＋」選 GitHub，把這個 repo 加進來（第一次要授權 GitHub）。
3. 貼上這段：

   > 照 `值班規則.md`，檢查 `值班表-2026-11.csv` 有沒有違反規則。
   > 人員與請假資料在另外兩個 csv。每一個問題都寫出日期、人、違反哪一條。

4. 看它列出來的問題，再追問：

   > 你列的這些，哪幾條你不確定？有沒有哪一條其實不算違規？

5. 想再進一步：

   > 幫我改到全部符合規則，改動越少越好。改完再照規則檢查一次給我看。

### 提示

它說「都檢查完了」不算數；自己挑一兩條回 csv 對對看。

## 練習二：口述的規則

規則不是整理好的文件，而是一位總醫師對著手機講十分鐘的逐字稿。請 AI 先整理出規則、列出要回頭問的地方，
再拿去檢查 11 月班表。見 [`練習二-口述的規則/`](練習二-口述的規則/說明.md)。

## 練習三：從舊班表找規則

沒有規則文件，只有 8–10 月三個月排好的班表和請假紀錄。請 AI 反推規則並附證據，最後跟 `值班規則.md` 對答案。
見 [`練習三-從舊班表找規則/`](練習三-從舊班表找規則/說明.md)。
